# Security Policy

Do not open a public issue for a suspected vulnerability or exposed secret. Use GitHub’s private vulnerability-reporting feature when available.

Never commit credentials, tokens, private keys, passwords, private hostnames, or local absolute paths. Synthetic examples must use unmistakable placeholders such as `<TOKEN>` and `<USER_HOME>`.

Supported security work currently covers the latest `main` branch. This research software is not safety-certified and should not directly control pressure, temperature, or electrical hardware.
