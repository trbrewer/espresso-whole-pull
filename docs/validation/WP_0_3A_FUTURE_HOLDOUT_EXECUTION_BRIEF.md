# WP-0.3A — future independent-holdout execution brief

**Status:** `NOT_AUTHORIZED_NO_QUALIFYING_HYDRAULIC_HOLDOUT`  
**Physical validation:** `NOT_ESTABLISHED`

This brief is for a future governed task after a qualifying dataset is
acquired. It does not authorize access, solver execution, scoring, model
selection, or another mechanism.

## Entry gate

Before execution, an independent reviewer must confirm:

1. persistent source identity and file hashes;
2. analysis and publication rights;
3. time-resolved basket-node pressure and outlet mass or flow;
4. basket area, bed depth, dose, preparation, temperature, and timing;
5. measurement uncertainty sufficient to set numerical thresholds;
6. independence from the Waszkiewicz campaign and all WP02 choices;
7. sealed score-bearing values until mappings, exclusions, groups, metrics,
   thresholds, software, and invocation counts are committed.

Failure of any item ends the task without opening the score-bearing values.

## Frozen comparison branches

- R0 only where its scientific scope is meaningful;
- constant-R1 as the constant-permeability control;
- the unmodified v0.2.0 WP02 optional closure.

No branch-specific fitting, new mechanism, parameter change, time shift,
amplitude scaling, or result-selected exclusion is permitted.

## Execution outline

The future task must generate fresh cases from committed inputs, use one
recorded executable for all comparable branches, pass numerical and
conservation gates before scoring, and invoke the score-bearing analyzer at
most once. Strict interpolation is allowed only within measured time support.
Undefined correlation fails a time-shape claim. Results must be reported
whether favorable or unfavorable, with failure-atomic output.

The present contract deliberately contains no numeric performance threshold:
none can be derived without an identified dataset's measurement uncertainty.
A future amendment may bind those uncertainty-derived values before access,
but may not select them from model performance.

## Claim ceiling

A future passing comparison can establish transfer only for its declared
apparatus, coffee, preparation, pressure range, observable, and time interval.
It cannot by itself establish full poroelastic deformation, cross-rig
universality, early wetting, channeling, fines, chemistry, taste, or a
universal permeability law.
