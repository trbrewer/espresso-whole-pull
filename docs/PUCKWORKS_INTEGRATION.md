# Puckworks Integration

Puckworks is the external public evidence/model/data dependency. This repository uses a machine-readable full-commit lock and deterministic checkout-and-verification script, not a Git submodule.

No rights-restricted data is copied. Future adopted inputs must record model IDs, units, pressure nodes, evidence roles, uncertainty, and rights status.

The recorded commit is historical continuity, not a claim of current alignment. Reviewing current Puckworks `main` is the first post-bootstrap scientific task.
