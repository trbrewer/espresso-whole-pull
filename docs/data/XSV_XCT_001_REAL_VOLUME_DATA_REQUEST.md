# XSV-XCT-001 minimum real-volume data request

XSV-XCT-001 completed the processed-data route, but no rights-cleared binary or grayscale volume was publicly retrievable or locally supplied. This document is an owner-facing request specification only. No message has been sent.

The minimum useful package is:

- original or reconstructed grayscale XCT volume;
- binary segmentation used in the publication, if available;
- voxel dimensions and scan-axis orientation;
- identities of crops or subvolumes used for flow calculations;
- phase-label convention;
- source flow boundary conditions and published directional-permeability mapping;
- segmentation procedure and threshold; and
- license or permitted-use and redistribution statement.

The highest-value package would contain the exact Wadsworth et al. binary flow domains for all three directions, linked unambiguously to the 22 processed sample identities. Exact mask bytes and boundary semantics are necessary for exact cross-code parity. A different crop from the same scan would support only a same-scan independent-subvolume comparison.

Until such a package is obtained legitimately:

`REAL_VOLUME_ACCESS_REQUIRED_FOR_FULL_CROSS_CODE_COMPARISON`

This request does not authorize author contact, protected-data access, physical scanning, or reconstruction of volumes from rendered figures.
