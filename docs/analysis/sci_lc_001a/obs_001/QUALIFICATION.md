# OBS-001 qualification boundary

The qualification uses bounded noncanonical fixtures only. Canonical Stage A
executor launches, graph keys, rows, trajectories, classifications, D4, X1,
alternate initial conditions, OpenFOAM launches, and Puckworks calls are zero.

The syntax-aware verifier compares the authorized base and candidate scientific
AST after removing only named diagnostic observer parameters, emitter calls,
and the observed-wrapper dispatch. The independent no-feedback analyzer rejects
diagnostic identifiers in classifier functions, assigned callback returns, RNG,
monkey-patching, diagnostic key identity, and scientific-state assignment.

For 2,212 dynamic terminal records, a conservative 200 KiB maximum stop record
projects to 442.4 MiB plus manifest, health, and filesystem overhead. This is
materially below RCA-002's approximately 6.37 GB ordinary-event stream. No
required stop record is capped away.
