# Measurement recommendation

`NO_COMPLETE_MEASUREMENT_SET`.

Before a mechanism-selection claim, acquire or qualify synchronized upstream pressure, basket pressure, flow, delivered mass, and first-drip timing with declared uncertainty. Bed-height resolution near 0.05 mm is only a model-informed starting assumption and requires a genuinely nested dynamic control before it can discriminate. Turbidity/fines and spatial/local-extraction channels remain unsupported here. This is a nomination for future design work, not experimental commissioning.
