source evaluation. HANDOFF.json binds an exact producer commit/tree, all three

Create an explicit checkout at the producer_commit in HANDOFF.json and set
PRODUCER to it. With NumPy/SciPy available:

```bash
python3 scripts/research_anchored_mass_delivery.py --producer "$PRODUCER" --model MASS
python3 scripts/research_anchored_mass_delivery.py --producer "$PRODUCER" --model EMPIRICAL
python3 scripts/research_anchored_mass_delivery.py --producer "$PRODUCER" --model SETTING_EMPIRICAL
python3 -m unittest discover -s tests -p test_research_anchored_mass_delivery.py
SCI_MD_MASS_DELIVERY_003_PRODUCER="$PRODUCER" python3 -m unittest discover -s tests -p test_research_anchored_mass_delivery.py
```

fraction-1 observation, not a reproduced physical shot. Outputs include alpha,
interval solute/average TDS, remaining solute, numerical allowance and analytical
anchor-error amplification. Average TDS is undefined for zero-width intervals.
No corpus access is needed. Real source states and row-level predictions stay private.
