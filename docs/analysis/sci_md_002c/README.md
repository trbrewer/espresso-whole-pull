# SCI-MD-002C

Status: `PROSPECTIVE_IMPLEMENTATION_IN_PROGRESS`

SCI-MD-002C is a reduced, one-dimensional, post-observation mechanism-discrimination screen for axial fines mobilization, transport, and downstream deposition. It is governed by the [decision and parallel-lane charter](DECISION_AND_PARALLEL_LANE_CHARTER.md), [closure-identifiability assessment](CLOSURE_IDENTIFIABILITY_ASSESSMENT.md), and [prospective protocol](PROTOCOL.md). Machine-readable authority is carried by `PARALLEL_LANE_DECLARATION.json` and the artifacts under `validation/cases/sci_md_002c/`.

This work does not change production physics and does not establish physical validation.
