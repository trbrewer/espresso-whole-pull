# Public provenance

This repository begins from a sanitized public derivative of the frozen and numerically qualified v0.1.4 source package.

The public derivative is not byte-identical to the archival package. Five files had host/path metadata replaced deterministically, and the source-manifest generator received a packaging-only adaptation for public repository metadata. Scientific inputs, governing physics, scientific configuration, numerical schemes, calibration values, and validation thresholds were not changed.

The exact archival identity is recorded in `ARCHIVAL_V0_1_4_SOURCE_IDENTITY.json`. The public transformation and structural proof are recorded in `PUBLIC_SANITIZATION_REPORT.json` and `PUBLIC_BASELINE_DERIVATION.json`.

Exact archival bytes and full generated evidence remain offline. They are not part of public Git history.
